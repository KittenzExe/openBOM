# Disclaimer

openBOM (openbom.exe.fyi) is an independent, open-source developer API for Australian weather data, maintained by KittenzExe.

**openBOM is not affiliated with The Australian Bureau of Meteorology (BOM).**

The project is developed as a non-profit, community-driven effort and will remain open source.

# Data Source

The data obtained is from `https://api.bom.gov.au` and was developed by observing publicly accessible network requests made by the Bureau of Meteorology website via browser developer tools and processing the publicly available data.

# API Stability

openBOM is not an official BOM API and upstream endpoints may change without notice. While efforts will be made to maintain compatibility, breaking changes may occur.

# Usage compliance

Data provided through openBOM originates from the Australian Bureau of Meteorology.

The use of openBOM means that you are also responsible to comply with the Bureau of Meteorology's copyright notice, license terms, and any applicable conditions of use.

This project does not claim ownership of Bureau of Meteorology data and is intended to make publicly available weather information easier for developers to consume. openBOM acts as a developer friendly interface, proxy, and processor for publicly available weather data. Any temporary caching or processing performed by the service exists solely to provide the API functionality.

For more information, see: https://reg.bom.gov.au/other/copyright.shtml
